# 🤖 AI Study Assistant

An AI-powered study assistant designed to help students understand technical topics in a simple and structured way.

## 🎯 Objective

The goal of this project is to provide students with quick and easy-to-understand explanations for academic and technical topics using Generative AI.

## ✨ Features

- 📚 Simple topic explanations
- 💡 Real-life examples
- 📝 Important points
- 🔎 Revision questions
- 🎓 Student-friendly responses
- 🤖 AI-powered content generation

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- GitHub

## ⚙️ How It Works

1. Enter a topic you want to learn.
2. Click **Explain Topic**.
3. The application sends the topic to the Gemini AI model.
4. The AI generates a structured explanation.
5. The result is displayed in the application.

## 🚀 Live Application

The application is deployed using Streamlit Community Cloud.
